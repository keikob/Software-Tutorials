Getting Started with R

Part 7: Working Directory

  • Your working directory is the folder on your computer that you’re operating out of during an R session.
  • By default, it’s going to be something very top-level like your “Documents” folder.
  • To find out what your working directory is, you can use the getwd() function (with empty parentheses), and this will return the filepath to the folder that is currently functioning as your home base.
getwd()
## [1] "C:/Users/ksb89187/OneDrive - University of Georgia/Documents"
  • So here, the working directory is my “Documents” folder, in my University of Georgia OneDrive, under my username (ksb89187) on the C drive.
  • The reason that the working directory matters is that once you get to the point where you’re reading in files, you have to tell R where they live on your computer.
  • You can do this by specifying the full exact filepath, like the output above, plus any additional subfolders and the file name, or you can start with a more local folder, set it as your working directory, and only have to specify files from there.
  • To set your working directory, you use setwd().
    • In the parentheses, put anything in the filepath that comes after your current directory in quotes.
    • For example, if I want to set my working directory to my “R Tutorials” folder, it is a top-level folder in my “Documents” folder, so I just put "R Tutorials" in the function call.
    • And when we check the working directory again, we can see that “R Tutorials” has been added to the filepath.
setwd("R Tutorials")
getwd()
## [1] "C:/Users/ksb89187/OneDrive - University of Georgia/Documents/R Tutorials"
  • So now, if I want to access one of the files in “R Tutorials”, I can just type "tutorial_1.R" and not specify all of the precending filepath.

  • If you want to set your working directory to something that’s not a subfolder of your current directory, you do have to specify more of the filepath.
  • So if I want to set my working directory to my “Downloads” folder, I can’t just type setwd("Downloads"), because “Downloads” is not a subfolder of “R Tutorials”.
setwd("Downloads")
## Error in `setwd()`:
## ! cannot change working directory
  • Instead, I have to specify the C drive, plus my username, and then “Downloads”.
setwd("C:/Users/ksb89187/Downloads")
getwd()
## [1] "C:/Users/ksb89187/Downloads"
  • Alternatively, as a non-coding method of setting your working directory, you can use the drop-down menus at the top of the screen.
  • Under the “Session” tab, it gives some options for setting the working director.
    • Source File Location: the folder location of the script you’re currently working in
    • File Pane Location: the folder displayed in the Files tab of the output pane
    • Choose Directory: choose any folder on your computer from a manual file explorer

  • If you close your R session and then open it again, your working directory will reset to the default.
  • You can also reset to the default using setwd("~").
setwd("~")
getwd()
  • So that’s how to find and change your working directory. Admittedly, this can be a bit of a clunky process, so R’s developers have created some useful ways to streamline it. We’ll get into one of them in the next tutorial.
